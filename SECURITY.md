# Security Policy

## 🔐 Reporting Security Vulnerabilities

If you discover a security vulnerability in any of our projects, please **DO NOT** open a public issue. Instead, please report it responsibly to us at:

📧 **amine.tech.div@gmail.com**

Subject: `[SECURITY] Vulnerability Report`

---

## What to Include

When reporting a vulnerability, please provide:

1. **Description** - What is the vulnerability?
2. **Location** - Which file/component is affected?
3. **Impact** - What could an attacker do?
4. **Reproduction Steps** - How to reproduce the issue?
5. **Proof of Concept** - Code or detailed steps (optional but helpful)
6. **Suggested Fix** - If you have one (optional)

---

## Response Timeline

- **24 hours**: Initial acknowledgment of your report
- **7 days**: Preliminary assessment and remediation plan
- **30 days**: Patch release (or timeline provided)
- **Coordinated Disclosure**: Public announcement after patch release
